# Run

Simple P2P chat rooms - no server needed.

## Features
- Create multiple rooms, each with a permanent share code
- Invite links (`#join=CODE`) + manual code entry
- Real-time P2P chat (PeerJS), file & PDF sharing
- Tasks, pinned messages, archive view
- Dark mode, English / Arabic (RTL) / French
- Local-first: all data stored in your browser (IndexedDB) with backup export/import

## Use
Open `index.html` in a browser. Create a room, share the code or invite link, and chat.
